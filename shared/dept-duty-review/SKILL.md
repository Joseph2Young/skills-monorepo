# 总行部门职能职责梳理

## 用途

把机构改革请示（基准文件）与部门比对表对照，逐部门梳理「主要职能 + 具体职责」，产出带增删改留痕的职能职责表。每个部门一个 Sheet，具体职责一事一条、颗粒度对齐、动作链完整。

## 触发词

- 梳理 / 过一遍 / 修订 + 部门名（如「梳理内控合规部」「把审计部过一遍」）
- 按【基准文件】梳理 XX 部门
- 生成总行部门职能职责梳理表

## 开工前必须确认（硬闸口，缺一不启动）

每次开工先向用户确认三项，逐项复述，得到明确确认后再动手：

1. **harness（输入材料）**：这次用哪份基准文件（机构设置请示 / 部门比对表），以及这次要梳理哪些部门（部门清单，可全量可部分）。
2. **动态规则**：本次生效的归口规则——员工行为管理怎么三分、文明优质服务（文优）归谁、大福利归谁，以及其他本次变动的规则。**这三项不写死，每次由用户现给。**
3. **输出参数**：版本号、输出路径（默认放 `总行一级部门调整/` 下）。

> 动态规则若用户未给全，只问缺的那一项，不替用户补。

## 逐部门流水线（六步，一个部门一个部门过）

对一个部门，按顺序走：

1. **分档**：判断这部门在基准文件里属哪档——①有明文职能 ②只提了调整动作、未描述职能 ③根本没提（等同"保持不变"）。
2. **取基线**：拉出基准文件里该部门的存量职责。明文有则用明文，明文无则用比对表（调整后职责列）存量。
3. **判增删改**：逐条比对，标记——哪条删、哪条增、哪条改、哪里与基准冲突。
4. **落规则**：套固定规则（审核原则、颗粒度、颜色约定，见 rules.md）+ 本次动态规则。
5. **写留痕**：按颜色约定写留痕，删除加横线、增/改/冲突分色（见 rules.md 颜色表）。
6. **查交叉**：标部门内重复【重】、部门间边界相邻【交】。

## 输出契约

- 一个 xlsx：`总行部门职能职责梳理-<版本号>.xlsx`
- 结构：总览 Sheet + 每部门一个 Sheet（列＝部门名称｜主要职能｜具体职责｜备注｜调整后职责）
- 具体职责用中文序号「一、二、三…」，一事一条，每条一个管理动作，颗粒度对齐
- 格式参照：`总行部门职能职责梳理-10.09修稿.xlsx`；颗粒度参照：`国有大行总行部门职责与二级机构设置信息.xlsx`

## 固定规则（写死，每次生效）

审核原则、颗粒度规范、颜色约定，见 `references/rules.md`；输出格式与颗粒度示例见 `references/output-format.md`。

## 留痕技术

openpyxl 富文本读写、语块级 diff、条目对齐，见 `references/trace-tech.md`；确定性脚本 `scripts/duty_trace.py`。

## 绝不做什么

- 基准文件里没有的职能，不编，标「待明确」
- 归属有争议的，不替用户拍板，标冲突交用户定
- 不把系统/平台/模型等工具手段写成职责
- 不改基准文件原文，只在产出副本上做留痕
