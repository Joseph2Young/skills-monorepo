# A股主线与核心候选筛选

按本文件进行候选研究；需要案例和使用说明时，阅读[方法与案例说明](references/方法与案例说明.md)。

## 确定信息边界

- 明确行情截止日期、时区和研究范围；沿用用户已明确的条件。
- 仅使用截止时点前可得的信息。把后续表现单独记录，不用于解释原来的选股理由。
- 区分行情日期与成员名单有效日期。只有最新成员时，说明不能据此精确还原历史成分。
- 使用用户提供或已授权的数据。缺少数据时列出所需字段，不指定或推测数据提供方。

## 检查必要数据

| 数据 | 所需内容 |
|---|---|
| 价格与成交 | 股票代码、日期、开高低收、昨收、成交量、成交额、换手率；说明单位与复权口径 |
| 行业与概念 | 行业/概念标识、名称、成分股、名单有效时间 |
| 涨停事件 | 涨停/炸板状态、连板数、首次及最后封板时间、开板次数；封单金额可选 |
| 板块联动 | 同一时点成分股涨跌幅、有效覆盖，以及核心与跟随股的表现 |
| 公告风险 | 披露时间、事项类别、可核验事实及核验状态 |

比较连续性时使用多个交易日，不能仅凭单日涨幅或成交额判断核心地位。校验代码、时间、单位、缺失和重复记录；缺失不得填作零。比较盘中广度时保持样本可比，并说明覆盖范围。

## 执行筛选

1. **定位主线。** 结合行业、概念及实际业务，识别值得观察的方向。概念标签只作为线索，不能代替业务关联。
2. **梳理梯队。** 比较连板高度、晋级、封板先后和反复开板情况，同时保留掉队股票。
3. **确认广度。** 判断上涨是多数成分共同参与，还是少数核心独强；说明分歧是否扩大。概念重叠时不要重复加总股票。
4. **区分角色。** 按下表分别比较，允许少选或不选，不为凑齐角色强行推荐。
5. **核验公告。** 检查催化是否仍有效，以及业绩、减持、担保、异动等事项。未核验明确标注，不写“无风险”。
6. **保留参与条件。** 选入候选不等于立即买入。涉及回踩时，最多使用“回踩不吃掉原有推进成果”这一原则性描述；具体认定与执行由使用者另行提供，不自行扩展。

| 角色 | 主要观察内容 |
|---|---|
| 高度核心 | 梯队地位、晋级情况、封板质量及同梯队淘汰情况 |
| 低位接力 | 同主线支持、较低连板位置、封板表现与相对强度 |
| 容量核心 | 连续成交规模、与主线的业务关联、相对表现及原有推进成果的保留 |

成交额大不等于资金净流入，也不自动代表承接强。成交活跃但价格明显回落的股票，要保留为反证或降低优先级。

## 输出结果

先给主线状态，再给候选表：

| 股票 | 角色 | 入选依据 | 不利证据 | 待确认条件 |
|---|---|---|---|---|

随后说明主要对照股为何未入选，以及哪些缺失数据限制了判断。区分已观察事实、研究判断和待核验信息；不能把历史案例的股票、价位或排序直接沿用为新结论。

## 保持披露边界

- 对外只列必要数据类型、字段、单位、有效时间和覆盖情况，不写提供方名称、接口、账号、本地目录或内部文件标识。
- 不提供或推导未披露的择时细节、内部参数、评分公式、代码或自动交易逻辑。
- 不把单次正向反馈写成已验证胜率，不编造实际成交或收益。
