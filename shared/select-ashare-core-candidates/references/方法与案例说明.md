# A股主线与核心候选筛选｜方法与案例说明

对外文字版 · 2026-10-28

## 用途

这份说明介绍一种候选筛选思路：先判断主线与板块状态，再区分高度、接力和容量角色，最后核验公告。它说明如何形成有依据的观察名单，不披露研究者的具体择时、执行规则或内部实现。

配套SKILL.md供AI遵循执行。使用者自行提供数据；只需满足字段和口径要求，不必使用特定平台。

## 方法路径

**行业与概念定位 → 涨停梯队 → 广度确认 → 核心分化 → 公告核验。**

- 行业与概念定位：股票是否属于同一业务方向，题材是否与实际业务相符。
- 涨停梯队：谁领先、谁晋级、谁掉队，分歧是否反复。
- 广度确认：多数股票共同上涨，还是仅少数核心保留强度。
- 核心分化：分别观察高度核心、低位接力和容量核心，避免拿同一标准比较所有股票。
- 公告核验：确认催化及其有效性，并检查可能改变判断的风险事项。

入选后仍须区分方向与参与条件。关于回踩，本说明仅保留一句原则：**回踩不吃掉原有推进成果。** 具体怎样认定、何时执行，不在公开内容范围内。

## 需要准备的数据

| 类别 | 最低要求 |
|---|---|
| 个股行情 | 多个交易日的代码、日期、开高低收、昨收、成交量、成交额、换手率 |
| 行业与概念 | 分类标识、名称、成分股及名单有效时间 |
| 涨停事件 | 状态、连板数、首次/最后封板时间、开板次数；封单信息按可得性补充 |
| 板块联动 | 同时点成分股涨跌幅、有效样本覆盖、核心与跟随股表现 |
| 公告事项 | 披露时间、事项类别、核验后的事实与尚未确定的内容 |

金额、数量及百分比必须注明单位；价格须明确复权口径。历史研究要区分当时成员与最新成员，比较广度时避免样本范围变化造成误判。缺失数据保持缺失，不用零替代。不要求提供订单流。

## 案例：增加一只容量核心候选

研究使用截至2026年10月27日收盘的行情。在汽车零部件与机器人相关方向，已有高度和接力观察对象，再增加容量角色，形成以下分工：

| 股票 | 角色 | 选择侧重点 |
|---|---|---|
| 襄阳轴承000678 | 高度核心候选 | 梯队高度与晋级表现 |
| 光洋股份002708 | 低位接力候选 | 同主线的较低连板位置及封板表现 |
| 双环传动002472 | 容量核心候选 | 持续成交容量、业务关联及相对强度 |

当时容量候选的主要对照如下，金额单位为亿元：

| 股票 | 27日涨跌幅 | 27日成交额 | 当时的取舍 |
|---|---:|---:|---|
| 双环传动 | +1.00% | 18.35 | 容量、主线关联和相对表现较均衡 |
| 三花智控 | -1.02% | 17.59 | 容量充足，但当天表现偏弱 |
| 拓普集团 | +0.57% | 12.64 | 可作为备选，成交额与涨幅略逊 |
| 万向钱潮 | -5.74% | 25.59 | 成交更大，但明显回落，不因放量就认定承接强 |

双环23、26、27日成交额约16.79、17.11、18.35亿元，收盘价分别为41.03、41.00、41.41。连续成交与收盘推进保留，使它有理由进入容量候选，而非只看单日涨幅榜。

同样保留不利证据：27日双环最高43.18、收盘41.41，存在明显冲高回落。因此当时结论是“容量核心候选”，并非已经确认的即时买点。该取舍属于综合研究判断，不代表它在全部股票中唯一最优。

案例提供者随后反馈双环28日涨停。本说明将其记为事后反馈，未完成独立核验，也没有实际成交与收益记录。研究讨论发生于28日，采用27日及以前行情；这不等同于已留存时间戳的27日晚推荐。该案例用于展示选择理由如何形成，不用于推导命中率或收益承诺。

## 使用方式

向AI提供配套SKILL及必要数据，明确：“按指定日期收盘为截止，分别研究高度、接力和容量核心，保留入选依据、对照股、不利证据和数据缺口；不得使用后续行情倒推理由。”

新任务必须重新评估，不沿用案例股票和价格。数据不足时，可以只给观察名单或得出等待结论。后续登记全部候选的结果，避免只保留上涨案例。
