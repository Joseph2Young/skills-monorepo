# Skill 03｜目标与结构设计

> 一门课就像一串项链：课程主题、学员痛点、目标、目录、知识点，必须用一条线串起来，前后一致。

## Part A：写课程目标（Step 3）

### 写法要求

- 站在"学员学完后能知道什么、会做什么、改善什么"的角度写。
- **禁止空话**："提升能力、增强意识、提高水平"一律打回。
- 45分钟课程，目标不要写大：1条总体目标 + 3-5条具体目标。
- 示例（园区客户初次拜访课）："看穿卡点、掌握切法、当场能用"。

### 检查项

1. 每条目标都能对应到 skill-02 挖出的某个痛点。
2. 目标可衡量、可实现（学员课后能做出什么动作？）。
3. 目标关键词与课程名称对得上（项链不断）。

### 提示词3（优化版）

```
请根据我提供的课程主题、学习对象和学习需求，帮我写这门课的课程目标。

【课程主题】请填写
【学习对象】请填写
【学习需求】（粘贴需求分析总结中"最值得优先纳入课程的需求"）

要求：
1. 目标要具体，不要空泛。
2. 不要写成"提升能力、增强意识、提高水平"这种话。
3. 要站在"学员学完后能知道什么、会做什么、改善什么"的角度来写。
4. 这是一门（请填写）分钟左右的银行内部课程，目标不要写得过大。
5. 请输出1条总体目标和3-5条具体目标。
```

## Part B：搭建三级目录课纲（Step 4）

### 先备料：小型资料库（最关键一步）

**没有素材搭出来的目录全是"看似正确的废话"——表面挺好，一上讲台全废。**

搭目录前必须向用户收资料，按效果排序：

| 优先级 | 资料 | 说明 |
|---|---|---|
| ★★★ | **真实案例**（8-16个最佳） | 什么时间、什么事、谁怎么处理的、结果如何，不用写太细。案例越多课纲质量越高（"16个案例"故事） |
| ★★★ | **工具/模板/表单** | 自己在用的筛选表、话术卡、检查清单 |
| ★★★ | **个人经验总结** | 自己踩过的坑、总结的窍门 |
| ★★ | 相关制度文件 | 不保密的才给 |
| ★★ | 现有课件 | 转PDF上传 |

- 红线：**行内保密信息、客户数据、内部经营数据绝不喂给AI。**
- 用户没素材：帮他想（找同事要案例、翻工作记录、回忆处理过的问题）；实在没有，降低预期并在课纲标注"此处需补充真实案例"。

### 目录结构规范

- 一级目录：一、二、三、（**不超过3个单元**）
- 二级目录：1. 2. 3.（每单元下按需拆分，**不是只能写两个**）
- 三级目录：（1）（2）（3）（**必须细化到三级**——不细化，PPT页里没东西可写）
- 结构选一种逻辑贯穿：Why-What-How / 流程型 / 问题解决型
- 每个一级单元标注预估时间，各部分相加 = 课程总时长

### 两项硬核检查

**① 项链一致性检查（前后一致）**
1. 找出课程名称里的关键词和数字说法（如"八看十课法"的"八"）。
2. 检查目标里是否对应（维度够不够八个？）。
3. 检查目录和知识点里是否都出现了同样的关键词/数字。
4. 不一致就二选一：改名称（八看→三看）或补内容。

**② 时间匹配检查（扁豆与生菜）**
- 各部分时间加起来 = 总时长（带多少预算买多少东西）。
- 难度高的知识点（扁豆）多给时间炖；简单的（生菜）30秒过，别硬讲。
- 45分钟的课，知识点选择必须克制，保证讲透。

### 提示词4（优化版）

```
请根据我提供的课程主题、学习对象、学习需求和课程目标，直接帮我设计这门课的
课程目录。另外，我上传了几个文件，是我的案例、工具模板和工作经验材料，我认为
非常好，请你务必参考我的资料给我搭课程大纲，不要让我太走出我的舒适区。

【课程主题】请填写
【学习对象】请填写
【课程目标】（粘贴Step 3确认的目标）

课程目录要求：
1. 这是一门（请填写）分钟左右的银行内部课程。
2. 必须采用清晰的课程结构（Why-What-How / 流程型 / 问题解决型），逻辑一致。
3. 必须细化到三级目录，编号格式：
   一级：一、二、三、（一级目录不超过3个）
   二级：1. 2. 3.
   三级：（1）（2）（3）
4. 每个一级单元标注预估时间，各单元时间相加等于课程总时长；难度高的内容
   多分配时间，简单的少分配。
5. 目录中的关键词、数字说法必须与课程名称、课程目标前后一致。
```

## 产出与交接

- 用户确认目录后，提醒：把确认的目录填入 Excel 课纲模板（课程名称/目标学员/学员问题/培训目标/一二三级目录/时间分配）。
- 课纲1.0完成，进入第二阶段（skill-04 配素材）。

## 常见坑

- "我每个二级目录下面就写俩三级" → 错，按实际内容灵活增加。
- 凭空让AI搭目录 → 全是正确的废话，讲不了。先喂资料库。
- AI给的目录里有自己讲不了的内容 → 三选一：**删除**（太陌生）/ **替换**（换成自己的同类方法）/ **跳一跳学下来**（稍学就能hold住的，留下当学习机会）。一门课只讲一套方法。
