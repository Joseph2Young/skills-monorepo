# Skill 06｜课件制作（PPT 1.0）

## Step 7：课纲 → 逐页制作脚本

### 页面类型（19类，关键教学环节不可删）

封面 → 讲师介绍 → 课程介绍 → 目标学员 → 学员痛点 → 课程目标 → 课程目录 → 开场导入 → 单元转场 → 单元勾兴趣 → 知识点讲解 → 案例分析 → 流程步骤/方法工具 → 互动练习 → 单元小结 → 课程回顾 → 行动计划 → 点睛升华 → 感谢页。

其中讲师介绍、课程目标、目录、开场导入、单元转场、案例、互动练习、单元小结、课程总结、感谢页**必须保留**。

### 拆页原则

1. 一页只讲一个核心观点。
2. 标题写结论式，不写概念词（"开场前三分钟决定七成沟通概率"，不是"开场的重要性"）。
3. 每个单元都有"勾兴趣→讲内容→加案例→做练习→做小结"结构。
4. 案例页：有场景、有问题、有分析、有启发。
5. 练习页：写清任务、规则、时间、产出。
6. 严格基于课纲拆页，不另起炉灶。

### 页数规划

| 时长 | 页数 |
|---|---|
| ≤30分钟 | 15-25页 |
| 45分钟 | 25-35页 |
| 60分钟 | 30-40页 |
| 1.5小时 | 35-55页 |
| 2小时 | 45-70页 |

### 逐页脚本字段（每页7项）

页码 / 页面类型 / 页面标题 / 核心观点 / 主要内容 / 建议呈现形式 / 是否需要素材。

## Step 8：AI生成PPT + 行内模板替换

### 工具操作要点

| 工具 | 操作 |
|---|---|
| **扣子 coze.cn（首选）** | 直接在聊天框发提示词8+逐页脚本，**不用点"PPT生成"按钮**；先上传一张行内PPT模板截图（或PPT文件）让它参考配色；导出点左侧"导出"（右侧的花钱）；积分：首次3000，每天签到1500，用完借家人手机号再注册 |
| 豆包（备选） | 需要点"PPT生成"按钮才能用 |
| Kimi经典版（备选） | 免费但额度有限；智能版约50元/月，不值，别花 |

可同时发给三家对比，选最好的一版。

### 行内模板替换法（只换三页）

1. 下载AI生成的PPT后，先检查：每页内容是否完整？有没有被AI压缩掉素材或练习？
2. **封面、目录、封底三页**：从行里模板复制过来，粘贴时选"保留原格式"。
3. 正文页用AI生成的即可。
