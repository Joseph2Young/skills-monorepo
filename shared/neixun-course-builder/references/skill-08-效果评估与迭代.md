# Skill 08｜效果评估与迭代

> 【说明】本技能整体为专业扩展：原材料（两次直播课）只讲到"提交三件套"，未展开训后评估。本技能基于课程中的理念（7天挑战、行动计划、好课"有效"标准）+ 通用培训评估方法（柯氏四级）构建，并按城商行场景适配。若后续线下课有官方评估方法，以官方为准替换。

## 评估逻辑：四层递进

| 层级 | 评什么 | 什么时候评 | 城商行适配工具 |
|---|---|---|---|
| L1 反应层 | 学员觉得课怎么样 | 下课当场 | 1分钟扫码反馈（3题：最有用的点/最想改的点/推荐指数1-10） |
| L2 学习层 | 学会了吗 | 课上已内置 | 课堂练习+简单测试的正确率（skill-05 的练习就是L2评估器） |
| L3 行为层 | 回去用了吗 | 训后1-4周 | 训后行动追踪（见下方"转化三件套"） |
| L4 结果层 | 对业务有贡献吗 | 训后1-3月 | 与课程痛点挂钩的业务指标变化 |

**45分钟内训课的务实取舍**：L1、L2必做，L3选做但强烈建议，L4只对重点课程做（如营销类课看客户转化率/联动率，运营类课看回退率/差错率）。

## L1 反应层：课堂反馈单（模板）

```
《课程名称》课后1分钟反馈
1. 今天课程里对你最有用的一个点是：______
2. 你最想改进的一点是：______
3. 你愿意把这门课推荐给同事吗？（1-10分）：______
```

解读：第3题均分<7 → 课程要大改；第1题高度集中 → 这个点就是课程的"钩子资产"，下次往开场放。

## L2 学习层：用课堂数据说话

- 练习完成度：各练习的正确率/完成率，哪个练习错得最多 → 这个知识点下次要多给时间（回 skill-03 调时间分配）。
- 简单测试错题分布：错得集中的题 = 讲得不到位的点。

## L3 行为层：训后转化三件套

课程里设计的行动计划（skill-07 收尾）在这里收口：

1. **7天挑战/任务卡**：学员抽到的训后任务，第7天在群内打卡接龙。
2. **通关文牒**：完成任务的盖章/积分，月度汇总到部门培训台账。
3. **抽样回访**：训后2-4周，抽样5-8名学员各问三个问题：
   - 课上哪招你用了？效果咋样？
   - 哪招没用上？卡在哪？
   - 还希望学什么？

对人力资源条线：L3数据是向部门证明内训价值的关键证据，建议按课程建简易追踪表（学员/任务/完成/效果一句话）。

## L4 结果层：指标挂钩（重点课程）

- 开发课程时就埋点：skill-02 挖的痛点如果可量化（报销回退率、投诉件数、联动营销单数），课前记录基线，训后1-3个月对比。
- 示例：《费用报销零回退四步法》→ 课前支行月均回退X笔 → 训后次月回退数。这就是课程"有效"的硬证据。

## 课程复盘与版本迭代

每次授课后填一张复盘卡，驱动版本升级：

```markdown
## 《课程名称》授课复盘卡（第X次授课，日期）
### 数据
- L1推荐指数均分：__ ｜ 练习正确率最低的环节：__ ｜ 训后任务完成率：__
### 三个问题
1. 哪个环节学员反应最好？（保留并强化）
2. 哪个环节卡了/冷了/时间不够？（调整）
3. 学员提出了什么课上没覆盖的真问题？（补入课纲）
### 迭代动作
- [ ] 课纲调整点：____（升级版本号，如2.0→2.1）
- [ ] 素材增补：____
- [ ] 时间重分配：____
```

迭代原则：
- 每次只改最痛的1-3个点，别全盘推翻。
- 改课纲让AI改（AI原生思维）：把复盘卡+旧课纲喂给千问，"按复盘意见修改课纲，其他部分不动"。
- 版本号留痕：课纲1.0（目录）→ 2.0（含素材练习，提交版）→ 2.x（训后迭代）。

## 检查清单（训后闭环）

- [ ] 练习/测试错题已分析？
- [ ] 训后任务有追踪（至少接龙打卡）？
- [ ] 复盘卡已填，迭代点已明确？
- [ ] 迭代版课纲已更新版本号并存档？
