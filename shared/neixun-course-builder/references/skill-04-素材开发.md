# Skill 04｜素材开发

> 知识点是牛肉，素材是老干妈。做菜好不好吃，就看你放没放那勺老干妈。素材的作用：帮学员消化和理解知识点。

## 底层原理：左右脑同刺激

- **左脑**喜欢理性分析：迷信数字、逻辑、因果 → 用**数据**征服。
- **右脑**喜欢颜色多、好玩、有意思 → 用**案例、视频、图片、故事**吸引。
- 好课左右脑同步刺激，不能只堆干货（太抽象、没意思）。

## 四类素材速查表

| 素材 | 刺激 | 用在哪 | 优先级 |
|---|---|---|---|
| **案例** | 右脑 | 讲痛点、讲方法、讲技巧时，随处可放 | ★★★（主料，越多越好） |
| **数据** | 左脑 | 表达"很严重""很有优势""变化很大"等形容词时，具象化 | ★★ |
| **视频** | 右脑 | 内容枯燥、不易理解时（政策法规、营销技巧、产品讲解） | ★★ |
| **图片** | 右脑 | 辅助表达，要能让人"看出"你想说的 | ★ |

## 各素材的打法

### 案例（主料）
- **写法四要素**：背景 → 冲突/挑战 → 方案动作 → 结果。
- 大案例（对公业务类）：分段呈现，一屏一屏讲（如T集团核心企业批量获客：公司情况→营销挑战→商票贷方案→结果）。
- 小案例（清收、零售类）：一页PPT呈现关键词即可。
- 讲完案例必须**引出方法**，案例是为方法服务的。
- 尽量图文并茂，不要一大段文字堆上去。
- 案例来源：自己在四川银行真实经历的业务场景（柜面、厅堂、外拓、部门协同），不靠AI凭空编。

### 数据（左脑的说服力）
- 凡是形容词（"特别重要""挑战很大"），就上数据具象化：市场份额、去年vs今年、客户变化。
- 技巧：挑一个最让人印象深刻的数据，让AI帮你渲染成能打动人的说法。
- 示范：干巴巴的"开场很重要" → "首次拜访开场顺利的客户，后续沟通概率约70%；开场不顺仅30%" → AI润色为"客户愿不愿意听你说，前三分钟就决定了。开场说得好，七成还能聊；说不好基本没下文。"

### 视频（没人能抵挡）
- 适用：讲政策法规觉得枯燥 → 去B站/抖音找；讲营销技巧、本行产品 → 可以自己拍（有学员拍古装版产品视频）；讲抽象方法 → 找类比视频（如F1换轮胎讲ACE流程法）。
- 原则：不沉迷视频本身，视频是为讲清知识点服务的。

### 图片（辅助表达，不是纯娱乐）
- 检验标准：学员能不能从图里"看出"你想表达的？（说客流量大，就要放真正人挤人的图。）

## 执行流程（AI人机协同）

1. 在同一千问对话中（课纲已上传过），发提示词5。
2. AI按模块输出素材建议后，**逐条跟用户过"hold住检查"**：
   - 能hold住 → 留下；
   - 不会操作（如"五步筛选法录屏"）→ 追问AI要替代方案或细化操作步骤；
   - 给的太少（如话术只给一条）→ 让它按角色补全（网格员/科长/经办人各一版）；
   - 完全搞不定 → 删除。
3. 全部确认后，**必须发闭环确认语**（不带这句AI会乱改、会压缩你的内容）：

```
所有素材都确认，请加到我的课程目录中，注意不要修改我原来课程大纲中的内容。
```

4. 若课纲后续有更新，重新发："我的课纲又更新了，请依据我最新的课纲再给我加素材"+ 提示词5。

## 提示词5（优化版）

```
请根据我提供的课程主题、学习对象、学习需求、课程目标、课程目录和关键新知，
直接帮我设计这门课需要配哪些教学素材。

要求：
1. 素材要贴近银行真实工作场景（柜面、厅堂、外拓营销、部门协同、风控合规等），
   实用、具体、便于讲授。
2. 不要只笼统地说"加案例"，要具体说明配什么、放在哪、有什么作用。
3. 素材要少而精，直接在知识点的后面标注素材类型，比如案例、视频、图片。
   太复杂的素材我做不来。
4. 请按课程模块输出建议素材，并说明：
   - 素材类型
   - 素材内容建议
   - 适合用在课程的哪个环节
   - 能帮助学员解决什么问题
5. 请把素材建议写得更适合讲师直接备课使用，让我一看就知道每个模块该准备什么。
```

## 检查清单

- [ ] 每个核心知识点后面都有至少一类素材？
- [ ] 案例≥3个，且都是真实业务场景？
- [ ] 每条素材都过了"hold住检查"？
- [ ] 素材少而精，不是堆砌？
- [ ] 已发闭环确认语，AI回复确认未改动原大纲？
