# Skill 07｜教学表达与授课呈现

> 表达流利只是最基础的要求。好课堂 = 有料 + 有效 + 有笑。
> 【说明】Part A 授课呈现框架为专业扩展（原材料集中在课程开发，授课技巧只在线下课展开）；Part B 说课稿与录制源自课程原文。

## Part A：授课呈现四段法【扩展】

### ① 开场导入（前3分钟定生死）

成人注意力短、秒秒钟走神，开场必须把注意力"勾"住。可选钩子：

| 钩子类型 | 做法 | 城商行示例 |
|---|---|---|
| 痛点提问 | 抛一个学员天天遇到的糟心事 | "上个月你的报销被回退了几次？" |
| 数据冲击 | 一个反直觉的数据 | "开场不顺的客户，七成没有下文" |
| 案例悬念 | 讲半个真实案例，结果课上揭晓 | "我们有个支行靠一张表把联动率翻了一倍，怎么做到的？" |
| 现场测试 | 3道小题自测，暴露差距 | "先测测你对新制度的三个理解对不对" |

开场必做三件事：亮身份（讲师介绍页要精心设计，让学员感到被尊重）→ 说清这课帮我解决什么 → 预告结构。

### ② 讲授节奏（讲一段、练一段）

- 每个单元固定节拍：**勾兴趣 → 讲内容 → 加案例 → 做练习 → 做小结**。
- 信息量克制：成人遗忘快，宁可少讲三个点、讲透两个点。
- 枯燥内容预处理：制度做成短视频、流程画成图、重点标粗标色（学员能感受到你倾注的精力，这就是被尊重）。
- 严肃主题（纪检廉洁党建）可以不搞笑，节奏和练习要求不变。

### ③ 提问与互动（尊重成人的自我意识）

- 多用"你们遇到过这种情况吗？""这事你怎么看？"——成人自我意识强，要交流不要灌输。
- 学员提出疑义：先接住（"你这个角度有意思"），再讲自己的解法，不硬压。
- 冷场预案：把开放题改成选择题/举手题；指定小组而非个人。
- 互动频次参考：每10-15分钟至少一次学员参与（抢答、对练、测试、讨论）。

### ④ 收尾转化（不只说"谢谢"）

1. **课程回顾**：带学员把知识点串一遍（对抗遗忘）。
2. **行动计划**：每人写/抽一个训后行动（结合 skill-05 的盲盒、通关文牒、群接龙）。
3. **点睛升华**：一句金句收尾（如"加入蓝海，逃离红海"），与课程主题呼应。

### 授课自检

- [ ] 开场3分钟内有钩子？
- [ ] 每个单元都有"勾-讲-案-练-结"？
- [ ] 全程至少3次学员参与？
- [ ] 收尾有回顾+行动计划+金句？

## Part B：说课稿与视频录制（Step 9-10）

### 说课稿结构（5-10分钟，口语化）

按此顺序写，AI代写时把最终课纲喂给它：

1. **自我介绍**：姓名、支行/部门（参赛宣言可选）
2. **课程针对谁**：学员对象，讲清分层
3. **解决什么问题**：学员痛点
4. **课程目录结构**：几部分，每部分讲什么
5. **核心知识点**：你的方法/模型/工具
6. **教学活动设计**：有案例、有练习、有游戏卡片等

写稿要求：口语化、像说话不像念稿；读一遍计时，控制在5-10分钟。

### 录制规范

| 项目 | 要求 |
|---|---|
| 画面 | 横屏、光线充足、露上半身、人在镜头中 |
| 声音 | 普通话、咬字清晰、声音大（离手机近或戴耳麦） |
| 环境 | 安静、背景整洁（书架/白墙） |
| 时长 | 5-10分钟 |
| 后期 | 不用加片头片尾、不用加字幕 |

两种录法：
- **站电视/大屏前**：适合能背稿或半脱稿的，PPT当背景，手机直接录。
- **杜加提词器**：手机下"杜加剪辑"APP → AI提词功能 → 稿子粘进去 → 对着摄像头念（眼珠转就行，别转脑袋）。

### AI协作要点

- 用语音输入（如"闪电说"类工具）跟AI交流写稿，比打字顺畅。
- 稿子改稿全部让AI干（AI原生思维），你只判断"这句像不像我说的话"。
