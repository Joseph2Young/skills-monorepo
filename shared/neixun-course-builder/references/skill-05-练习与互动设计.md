# Skill 05｜练习与互动设计

> 好的课程要有学有练。就像考驾照：科目一要刷模拟题，科目二科目三必须上车摸方向盘。教练一个人飙车、学员碰不到车，等于没教。

## 为什么必须练

- 成人学习特点决定：光听记不住，必须在课堂上现场体验和检验"我会不会"。
- 练习的作用：**消化和理解知识点**——不是讲师偷懒，也不是凑时间。

## 练什么：两条铁律

1. **不是每个知识点都练**。上车开门练一天，学员会生气——太简单的不练。
2. **关键动作和易错点才练**。倒库、S弯这种容易折的，必须练。对应到课程：核心方法、高频错误点，后面必须跟练习。

## 五种练习形式适配表

| 形式 | 适合什么 | 城商行示例 |
|---|---|---|
| 小组讨论 | 开放性问题 | "这个网点联动卡点，你们组认为责任在哪个环节？" |
| 案例研讨 | 有标准答案的分析题（给背景+问题，不同于案例分享） | 给出客户投诉背景，"这事该咋整？" |
| 角色扮演 | 话术、沟通类 | 一人扮客户一人扮理财经理，对练开场话术/电话邀约 |
| 实操演练 | 系统操作、写东西 | 现场用系统筛一遍沉睡客户；现场写一段需求说明书；分行应急预案模拟 |
| 简单测试 | 纯知识记忆（填空、选择、判断、连线） | 法规条文、产品要素、风险点连线题 |

## 游戏化设计（让练习有意思）

担心学员内向、仪式尴尬时，用游戏化和社交货币改造：

- **盲盒抽任务**：不透明盒里抽训后任务卡，回去就整。
- **通关文牒盖章**：完成各环节盖章，凑齐找讲师领奖品。
- **群内接龙**：训后行动接龙，讲师先找个"托"公开打个样。
- 痛点粉碎机全员抢答、60秒黄金话术对练、高情商救场情境挑战、一页纸通关——都是可直接套用的练习命名范式。

## 执行流程（AI人机协同）

1. 素材确认后的同一千问对话中，直接发提示词6（不用重新上传课纲）。
2. AI输出练习方案后，逐条跟用户过：
   - 练习便于课堂操作吗？（45分钟的课不能搞复杂沙盘）
   - 时间合理吗？
   - 担心效果不好（如学员内向）→ 跟AI明说顾虑，要趣味性替代方案，从中选一个。
3. 全部确认后，**必须发闭环确认语**：

```
练习确认，请加到我原来的课程大纲当中，注意不要修改我原来课程当中的内容。
```

4. 然后让千问输出最终课纲（含知识点+素材+练习）：

```
好的，这是我最终的课纲。现在请你把原来搭建的课纲加素材、加练习，给我形成
一版最终版本发过来。不要用表格形式，请用文本目录的形式列出来（方便我接下来
做PPT）。
```

## 提示词6（优化版）

```
请根据我提供的课程主题、学习对象、学习需求、课程目标、课程目录和关键新知，
直接帮我设计这门课的"练本领"环节。

要求：
1. 练习要紧扣课程目标和课程内容。
2. 这是一门45分钟左右的银行内部课程，练习设计要便于落地、讲师好操作，
   不搞复杂沙盘，以简单测试、案例分析、话术对练为主。
3. 不是每个知识点都配练习——简单知识点不练，关键动作和易错点必须练。
4. 请按课程模块输出适合安排的练习，并说明：
   - 练习名称
   - 练习类型（小组讨论/案例研讨/角色扮演/实操演练/简单测试）
   - 练习目标
   - 讲师怎么组织
   - 学员怎么参与
   - 最终产出什么
   - 大约需要多少时间
```

## 检查清单

- [ ] 核心方法、高频易错点后面都有练习？
- [ ] 简单知识点没硬凑练习？
- [ ] 每个练习写清了任务、规则、时间、产出？
- [ ] 练习总时长与课程时长匹配（45分钟课练习合计约10-15分钟）？
- [ ] 已发闭环确认语 + 拿到最终版课纲（知识点+素材+练习）？
