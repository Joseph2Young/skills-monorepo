# Skill 01｜选题定位（知识类→技能类）

> 好的选题是成功的一半。一门45-60分钟的内部课，只解决一类人在一个场景下的2-3个问题。

## 输入（先向用户收集4项）

1. 部门/岗位（如：总行公司金融部/分行办公室/支行柜面）
2. 培训对象（必须分层，见下方红线）
3. 目前想讲的方向/主题
4. 时长（默认45分钟）

## 选题四标准（逐项检查，缺一项就改）

| 标准 | 检查方法 | 不达标表现 |
|---|---|---|
| ①技能类，有动词 | 题目里有没有"如何营销/如何规避/如何识别/如何做好"这类动作 | "XX制度解析""XX产品介绍""XX概览" → 纯知识类，必须转 |
| ②聚焦一个具体场景 | 能说清学员在什么工作环节用这个内容 | "讲完普惠所有产品""党业融合" → 大而全，必须切小 |
| ③时长内能解决2-3个问题 | 45分钟讲透，不求全 | 目标写得太大实现不了，或太小显得课程没质量 |
| ④自己有干货 | 电脑里有案例、有工具、有经验 | 想法很美好但自己不精通、没资料 → 劝换主题，别硬上 |

## 学员分层红线

- **禁止**：全体员工、全体客户经理、全体理财经理（除非是新政策新法规全员宣贯）。
- **正确**：按岗位 + 经验/技能水平分层，如"入职1-3年的对公客户经理""新转岗的厅堂经理""新提任的网点负责人"。
- 对象决定需求：分层不同，痛点完全不同，后边的课程内容才精准。

## 知识类→技能类转化示范（城商行真实案例）

| 原题（知识类） | 转化后（技能类） | 转化逻辑 |
|---|---|---|
| 党业融合 | 如何找准党建工作与业务发展的结合点 / 如何避免党建活动与业务"两张皮" | 先定对象（基层党支部书记）→ 找他的痛点（各做各的、活动没业务成果）→ 取一个角度 |
| 督查督办制度解析 | 如何提升督办任务闭环效率 / 任务久拖不结怎么办 / 如何做好收口工作 | 对象（各部门督办责任人）→ 痛点（只催进度不解决卡点、标准模糊、无PDCA闭环） |
| 经费报销系统讲解 | 一次做对关：支行日常费用报销零回退实操四步法 / 高频错误怎么识别与规避 | 从"讲系统"转为"讲易错点+场景应用" |
| 绿色转型背景下的机遇与挑战 | 逃离红海加入蓝海：绿色转型客户营销策略与风险防范 | 报告体→技能体：认识、挖掘、把控三段 |
| 舆情政策及制度 | 稳得住场：综合管理中的舆情初期回应与沟通技巧 / 避坑指南：办公人员必须掌握的舆情合规红线 | 制度→场景化动作 |

## 执行流程

1. 收集4项输入。
2. 若题目是知识类/大而全/对象不分层，**直接指出问题**，用下方提示词1生成3-5个技能类版本。
3. 每个版本标注：训练什么能力、适合什么对象。
4. 推荐1个，说明理由；用户确认或给修改意见。
5. 确认后进入 skill-02。

## 提示词1（优化版，复制到千问国际版使用）

```
你现在是一位资深企业内训选题大师，熟悉地方城商行的业务条线（公司金融、零售金融、
厅堂运营、风险合规、计划财务、金融科技、综合管理）。请根据我提供的信息，帮我把下面
这个偏知识介绍型的课程题目，改成更适合企业培训的技能类课程题目。

我的岗位：四川银行（请填写部门、岗位，如"分行办公室综合管理岗"）
我的培训对象：（请填写，必须分层，如"各部门兼职综合管理人员，入职1-3年"）
目前的课程方向：（请填写）
培训时长：（请填写，默认45分钟）

要求：
1. 改写后的题目要体现学员学完后会做什么，而不只是知道什么，题目中带动作。
2. 题目要贴近银行真实工作场景（柜面、厅堂、外拓、政银联动、风控、报销、督办等），
   适合45分钟左右讲透。
3. 请提供3-5个改写版本。
4. 并说明每个版本分别适合训练什么能力、适合什么对象。
5. 最后推荐1个最适合做成技能类课程的题目，并说明理由。
```

## 常见坑（主动提醒用户）

- AI给的题目"太高大上，我讲不了" → 大概率是没喂自己的资料。选题阶段可以先不喂，但搭目录前必须喂（见 skill-03）。
- 选题定不下来 → 回到痛点：你的学员最近被什么事搞得最烦？那件事就是选题。
- 严肃主题（纪检、廉洁、党建）可以不要"有笑"，但技能类和场景化要求不变。
