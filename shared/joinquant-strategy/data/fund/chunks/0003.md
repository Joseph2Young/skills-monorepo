#### 获取单支基金数据

获取单支基金的信息.

**调用方法**

```
get_security_info(code)
```

**参数**

- code: 基金代码

**返回值**

- 一个对象, 有如下属性:

- display\_name # 中文名称
- name # 缩写简称
- start\_date # 上市日期, [datetime.date] 类型
- end\_date # 退市日期， [datetime.date] 类型, 如果没有退市则为2200-01-01
- type # 类型 etf(ETF基金)，fja（分级A），fjb（分级B）,fjm(分级母基金），lof(场内交易开发基金），mmf(场内交易货币基金）
- parent # 分级基金的母基金代码

**示例**

```
get_security_info('159901.XSHE').start_date #获取深100ETF的上市日期
```
