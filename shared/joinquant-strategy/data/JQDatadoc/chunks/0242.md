- 获取一只股票某个字段数据\*\*

```python
q = query(
    indicator
).filter(
    indicator.code == '000004.XSHE'
)
df = get_fundamentals(q, '2015-10-15')
# 打印出每股收益EPS(元)
print(df['eps'][0])
```
