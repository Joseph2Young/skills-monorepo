- 获取某只股票在某天的市值数据

```python
# 查询'000001.XSHE'的所有市值数据, 时间是2015-10-15
q = query(
    valuation
).filter(
    valuation.code == '000001.XSHE'
)
df = get_fundamentals(q, '2015-10-15')
# 打印出总市值
print(df['market_cap'][0])

>>> 1598.2791
```
