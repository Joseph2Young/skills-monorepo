```python
get_extras(info, security_list, start_date='2015-01-01', end_date='2015-12-31', df=True, count=None)
```

**描述**

- 获取基金累计净值/基金单位净值/场外基金的复权净值

**返回结果**

- 返回一个 dataframe，每一行对应数据表中的一条数据， 列索引是您所查询的字段名称
  

**注意**

- 为了防止返回数据量过大, 我们每次最多返回5000行
- 不能进行连表查询，即同时查询多张表的数据
- **新增 [run\_offset\_query](https://www.joinquant.com/help/api/doc?name=JQDatadoc&id=10530)方法，支持分批从数据库提取超5000条的数据，上限20万条**
- **新增 [get\_table\_info(table)](https://www.joinquant.com/help/api/doc?name=JQDatadoc&id=10745) 方法，支持查询数据表中的字段信息**

  

**query函数的使用技巧**

- query函数的更多用法详见：[query简易教程](https://www.joinquant.com/view/community/detail/16411)

**基金净值参数**

- **info**[ 'acc\_net\_value', 'unit\_net\_value', 'adj\_net\_value'] 中的一个
- **security\_list**：基金列表
- **start\_date/end\_date**：开始结束日期, 同 [get\_price]。
- **df**：返回[pandas.DataFrame]对象还是一个dict
- **count**：**与 start\_date 二选一, 不可同时使用**, 必须大于 0. 表示取 end\_date 往前的 count 个交易日的数据

| 指定info字段 | 返回信息 |
| --- | --- |
| acc\_net\_value | 基金累计净值 |
| unit\_net\_value | 基金单位净值 |
| adj\_net\_value | 场外基金的复权净值 |
