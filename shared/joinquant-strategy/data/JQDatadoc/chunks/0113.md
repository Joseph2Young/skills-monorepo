> Path: 沪深A股接口 / 股票ST信息 / 参数

##### 参数

| 参数名称 | 参数说明 | 注释 |
| --- | --- | --- |
| info | ['is\_st'] | 是则返回 True，否则返回 False |
| start\_date/end\_date | 开始/结束日期, |  |
| df | True或False | df=True返回[pandas.DataFrame]对象 列索引是股票代号, 行索引是[datetime.datetime]  df=False，返回一个dict, key是股票代号，案例如下 |
| count | 数量 | 与 start\_date 二选一, 不可同时使用, 必须大于 0。 表示取 end\_date 往前的 count 个交易日的数据 |
