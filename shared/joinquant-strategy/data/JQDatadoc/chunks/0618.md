> Path: 基金 / 获取ETF跟踪指数信息 / 参数

##### 参数

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | varchar(12) | 基金代码 |
| name | varchar(50) | 基金简称 |
| pub\_date | DATE | 公告日期 |
| start\_date | DATE | 生效日期 |
| end\_date | DATE | 失效日期（未失效则为空） |
| traced\_index\_name | varchar(100) | 跟踪指数名称 |
| traced\_index\_code | varchar(12) | 跟踪指数代码（不支持的指数填充为空） |

**示例：**

```python
# 查询510190追踪的指数信息
q = query(finance.FUND_INVEST_TARGET).filter(finance.FUND_INVEST_TARGET.code== '510190.XSHG')
df = finance.run_query(q)
print(df)
```
