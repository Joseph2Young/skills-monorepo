### 债券票面利率

- 历史范围：上市至今；更新时间：每日19：00、22:00更新

```python
from jqdatasdk import *
df=bond.run_query(query(bond.BOND_COUPON).limit(n))
```

**描述**

- 获取债券基本信息数据

**返回结果**

- 返回一个 dataframe，每一行对应数据表中的一条数据， 列索引是您所查询的字段名称
  

**注意**

- 为了防止返回数据量过大, 我们每次最多返回5000行
- 不能进行连表查询，即同时查询多张表的数据
- **新增 [run\_offset\_query](https://www.joinquant.com/help/api/doc?name=JQDatadoc&id=10531)方法，支持分批从数据库提取超5000条的数据，上限20万条**
- **新增 [get\_table\_info(table)](https://www.joinquant.com/help/api/doc?name=JQDatadoc&id=10745) 方法，支持查询数据表中的字段信息**

  

**query函数的使用技巧**

- query函数的更多用法详见：[query简易教程](https://www.joinquant.com/view/community/detail/16411)

**债券票面利率参数**

- **query(bond.BOND\_COUPON)**：表示从bond.BOND\_COUPON这张表中查询债券票面利率信息数据，其中bond是库名，BOND\_COUPON是表名。bond库中的表都可以使用run\_query方法调用,在查询表数据时还可以指定所要查询的字段名，格式如下：query(库名.表名.字段名1，库名.表名.字段名2，多个字段用逗号分隔进行提取；query函数的更多用法详见：[[query简易教程]](https://www.joinquant.com/view/community/detail/16411)- **bond.BOND\_BASIC\_INFO**：获取债券票面利率数据，**表结构和字段信息如下**：
  - **filter(bond.BOND\_COUPON.code==code)**：指定筛选条件，通过bond.BOND\_COUPON.code == '131801' 可以指定债券代码来获取债券票面利率信息数据；多个筛选条件用英文逗号分隔。
  - **limit(n)**：限制返回的数据条数，n指定返回条数。
