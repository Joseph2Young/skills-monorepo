### 获取单支可转债标的信息

试用账号历史范围：前15个月~前3个月 ; [正式账号历史范围：不限制](https://docs.qq.com/sheet/DRWx0UWNUVlNzdXl3?tab=e9no84)

```python
get_security_info(code)
```

**描述**

- code: 证券代码
- 使用方式:**接口+.属性**，具体属性说明如下图

| 属性 | 名称 | 备注 |
| --- | --- | --- |
| display\_name | 中文名称 |  |
| name | 缩写简称 |  |
| start\_date | 上市日期 | [datetime.date] 类型 |
| end\_date | 退市日期 | [datetime.date] 类型,  如果没有退市则为2200-01-01) |
| type | 类型 | conbond(可转债) |
