### 获取行业列表

- 历史范围：2005年至今；更新时间：8:00更新

```python
get_industries(name='zjw', date=None)
```

**描述**

- 获取行业列表
- [行业列表](https://www.joinquant.com/help/api/help#plateData:%E8%A1%8C%E4%B8%9A%E7%B1%BB)

**参数**

name: 行业代码，默认值为'zjw',其他行业取值如下：- "sw\_l1": 申万一级行业
- "sw\_l2": 申万二级行业
- "sw\_l3": 申万三级行业
- "jq\_l1": 聚宽一级行业
- "jq\_l2": 聚宽二级行业
- "zjw": 证监会行业

**返回值**

pandas.DataFrame， 各 column 的含义如下:- index: 行业代码
- name: 行业名称
- start\_date: 开始日期
