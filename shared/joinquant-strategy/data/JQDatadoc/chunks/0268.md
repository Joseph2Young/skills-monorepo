> Path: 股票-单季度/年度财务数据 / 获取多个标的在指定交易日范围内的市值表数据 / 示例

##### 示例

```python
from jqdatasdk import *
# 传入单个标的
df1 = get_valuation('000001.XSHE', end_date="2019-11-18", count=3)
print(df1)

# 传入多个标的
df2 = get_valuation(['000001.XSHE', '000002.XSHE'], end_date="2019-11-18", count=3)
print(df2)
```
