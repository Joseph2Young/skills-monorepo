### get_index_valuation 获取指数估值数据

历史范围：2005年至今;9点更新总股本及流通股本数据, 盘后 17:00更新剩余字段  
对外更新时间

```python
get_index_valuation(security_list, start_date=None, end_date=None, fields=None, count=None)
```

**描述**

- get\_index\_valuation：获取指数估值数据；目前只支持部分指数。
    
  **列表：['000001.XSHG','000016.XSHG','000300.XSHG', '000905.XSHG','000852.XSHG','000688.XSHG','399001.XSHE','399006.XSHE','000510.XSHG' ]**

  

**参数**

- security\_list: 标的code字符串列表或者单个标的字符串
- end\_date: 查询结束时间
- start\_date: 查询开始时间，不能与count共用
- fields: 支持所有财务数据中市值表的字段，返回结果中总会包含code、day字段，**可用字段如下图：**
- code:股票代码, day:日期
- count: 表示往前查询每一个指数count个交易日的数据，如果期间无指数，则该指数返回的市值数据数量小于count

**返回**

- dataframe

**注意**

- 每次最多返回10000条数据，更多数据需要根据标的或者时间分多次获取

| **列名** | **列的含义** | **解释** | **公式** |
| --- | --- | --- | --- |
| code | 股票代码 | 带后缀.XSHE/.XSHG |  |
| day | 日期 | 数据日期 |  |
| pe\_ratio | 市盈率(PE, TTM) | 每股市价为每股收益的倍数，反映投资人对每元净利润所愿支付的价格，用来估计股票的投资报酬和风险 | 指数市盈率（PE，TTM）=指数总市值/(成分股总市值/成分股pe\_ratio) |
| turnover\_ratio | 换手率(%) | 指在一定时间内市场中股票转手买卖的频率，是反映股票流通性强弱的指标之一。 | 指数换手率=SUM(成分股流通股本\*成分股换手率)/SUM(成分股流通股本) |
| pb\_ratio | 市净率(PB) | 每股股价与每股净资产的比率 | 指数市净率=指数总市值/(成分股总市值/成分股pb\_ratio) |
| ps\_ratio | 市销率(PS, TTM) | 市销率为股票价格与每股销售收入之比，市销率越小，通常被认为投资价值越高。 | 指数市销率TTM= 指数总市值/(成分股总市值/成分股ps\_ratio) |
| pcf\_ratio | 市现率(PCF, 现金净流量TTM) | 每股市价为每股现金净流量的倍数 | 指数市现率(PCF, 现金净流量TTM)=指数总市值/(成分股总市值/成分股pcf\_ratio) |
| capitalization | 总股本(万股) | 公司已发行的普通股股份总数(包含A股，B股和H股的总股本) | 指数总股本=SUM(成分股总股本) |
| market\_cap | 总市值(亿元) | A股收盘价\*已发行股票总股本（A股+B股+H股） | 指数总市值=SUM(成分股总市值) |
| circulating\_cap | 流通股本(万股) | 公司已发行的境内上市流通、以人民币兑换的股份总数(A股市场的流通股本) | 指数流通股本=SUM(成分股流通股本) |
| circulating\_market\_cap | 流通市值(亿元) | 流通市值指在某特定时间内当时可交易的流通股股数乘以当时股价得出的流通股票总价值。 | 指数流通市值=SUM(成分股流通市值) |
| pe\_ratio\_lyr | 市盈率(PE) | 以上一年度每股盈利计算的静态市盈率. 股价/最近年度报告EPS | 指数市盈率（PE，LYR）=指数总市值/(成分股总市值/成分股pe\_ratio\_lyr) |
| pcf\_ratio2 | 市现率(PCF,经营活动现金流TTM) | 每股市价为每股现金净流量的倍数(jqdtasdk1.9.5新增) | 指数市现率(PCF, 经营活动现金流TTM)=指数总市值/(成分股总市值/成分股pcf\_ratio2) |
| dividend\_ratio | 股息率(TTM) % | 使用除权除息日进行统计(jqdtasdk1.9.5新增) | 指数股息率(TTM)=SUM(成分股总市值\*成分股股息率)/指数总市值 |
| free\_cap | 自由流通股本(万股) | 流通股本-其他扣除数(如高管限售25%)(jqdtasdk1.9.5新增) | 指数自由流通股本=SUM(成分股自由流通股本) |
| free\_market\_cap | 自由流通市值(亿元) | A股收盘价\*自由流通股本(jqdtasdk1.9.5新增) | 指数自由流通市值=SUM(成分股自由流通市值) |
| a\_cap | A股总股本(万股) | 公司已发行的普通股股份A股总数(jqdtasdk1.9.5新增) | 指数A股总股本=SUM(成分股A股总股本) |
| a\_market\_cap | A股总市值(亿元) | A股收盘价\*A股总股本(jqdtasdk1.9.5新增) | 指数A股总市值=SUM(成分股A股总市值) |
