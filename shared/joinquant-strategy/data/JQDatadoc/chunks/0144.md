> Path: 沪深A股接口 / 龙虎榜数据 / 参数

##### 参数

| 参数 | 名称 | 注释 |
| --- | --- | --- |
| stock\_list | 股票列表 | 一个股票代码的 list。 当值为 None 时， 返回指定日期的所有股票。 |
| start\_date | 开始日期 | 一个字符串或者 [datetime.datetime]/[datetime.date] 对象 |
| end\_date | 结束日期 | 一个字符串或者 [datetime.date]/[datetime.datetime] 对象 |
| count | 数量 | 交易日数量， 可以与 end\_date 同时使用， 表示获取 end\_date 前 count 个交易日的数据(含 end\_date 当日) |
