##### 示例

- 获取某一天的融券标的列表

```python
# 获取融券标的列表，并赋值给 marginsec_stocks
marginsec_stocks= get_marginsec_stocks(date='2018-07-05')
print(marginsec_stocks[:5])
['000001.XSHE', '000002.XSHE', '000006.XSHE', '000009.XSHE', '000012.XSHE']
```

- 判断某只股票是否在融券列表内

```python
# 判断平安银行是否在可融券列表
'000001.XSHE' in get_marginsec_stocks(date='2018-07-05')
>>> True
```
