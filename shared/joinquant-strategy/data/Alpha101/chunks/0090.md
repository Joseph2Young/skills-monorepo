#### alpha_083

```python
alpha_083(enddate, index='all')
```

- 输入：
- enddate: 必选参数，计算哪一天的因子
- index: 默认参数，股票指数，默认为所有股票’all’
- 输出：
- 一个 Series：index 为成分股代码，values 为对应的因子值
- 因子公式：
- ((rank(delay(((high - low) / (sum(close, 5) / 5)), 2))\* rank(rank(volume))) / (((high - low) / (sum(close, 5) / 5)) / (vwap - close)))
