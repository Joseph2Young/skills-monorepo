#### alpha_047

```python
alpha_047(enddate, index='all')
```

- 输入：
- enddate: 必选参数，计算哪一天的因子
- index: 默认参数，股票指数，默认为所有股票’all’
- 输出：
- 一个 Series：index 为成分股代码，values 为对应的因子值
- 因子公式：
- ((((rank((1 / close))\* volume) / adv20)\* ((high\* rank((high - close))) / (sum(high, 5) / 5))) - rank((vwap - delay(vwap, 5))))
