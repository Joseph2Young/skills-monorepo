#### alpha_039

```python
alpha_039(enddate, index='all')
```

- 输入：
- enddate: 必选参数，计算哪一天的因子
- index: 默认参数，股票指数，默认为所有股票’all’
- 输出：
- 一个 Series：index 为成分股代码，values 为对应的因子值
- 因子公式：
- ((-1\* rank((delta(close, 7)\* (1 - rank(decay\_linear((volume / adv20), 9))))))\* (1 + rank(sum(returns, 250))))
