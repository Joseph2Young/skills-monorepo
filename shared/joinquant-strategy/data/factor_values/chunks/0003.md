### 获取所有因子

```python
get_all_factors()
```

描述：获取聚宽因子库中所有的因子code和因子名称

**参数**：无

**返回**：pandas.DataFrame，

- factor:因子code
- factor\_intro:因子说明
- category:因子分类名称
- category\_intro:因子分类说明
  **示例**：

```python
#获取聚宽因子库所有因子
from jqfactor import get_all_factors 
print(get_all_factors())
```
