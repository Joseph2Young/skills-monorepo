#### 获取所有期货信息

获取平台支持的所有期货数据

**调用方法**

```
get_all_securities(types=['futures'])
```

这里请在使用时注意防止未来函数。

返回

- display\_name # 中文名称
- name # 缩写简称
- start\_date # 开始日期, [datetime.date] 类型
- end\_date # 结束日期，[datetime.date] 类型
- type # 类型，futures(期货)

一个[pandas.DataFrame]

**示例**

```python
#获取所有期货数据中的前5条
get_all_securities(['futures']).head()

A0505.XDCE       豆一0505  a0505 2003-11-17 2005-05-20  futures
A0507.XDCE       豆一0507  a0507 2004-01-16 2005-07-14  futures
A0509.XDCE       豆一0509  a0509 2004-03-15 2005-09-14  futures
```
