#### 获取单只期货信息

获取单支期货的信息.

**调用方法**

```python
get_security_info(code)
```

**参数**

- code: 期货代码

**返回值**

一个对象, 有如下属性:

- display\_name # 中文名称
- name # 缩写简称
- start\_date # 开始日期, [datetime.date] 类型
- end\_date # 结束日期，[datetime.date] 类型
- type # 类型，futures(期货)

**示例**

```python
# 输出沪深300股指期货信息
get_security_info('IF1605.CCFX')
```
